# School Management Mobile — Starter Project

Flutter Android starter project. School name can be edited from the dashboard settings and a school logo can be selected from the device gallery. Basic student and teacher records are saved locally using SharedPreferences.

Included starter screens: dashboard, student list/add, teacher list/add, attendance placeholder, reports placeholder, and quick action placeholders for exams/DMC and ID/result/fee cards.

**Update note:** This ZIP contains the current school app source, including the redesigned DMC PDF, launcher-icon generation workflow, Staff Portal permission visibility, and the existing backup/restore and PDF share features. Read `README_FINAL_UPDATE_UR.txt` for exact changes and important limitations. The Staff Portal permission display is not yet a complete security boundary for every data operation. Firebase permission-denied errors still require checking the live Firebase project rules and account/school ownership. This source was not compiled or tested on a physical Android device in this environment.
